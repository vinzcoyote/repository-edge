## What’s changed

* Forked from the original jhollowe-addons ser2net addon.
* Added configurable serial communication parameters to the Home Assistant interface:
  * Network mode: TCP / RFC2217
  * Baud rate
  * Data bits
  * Parity
  * Stop bits
  * Flow control
  * No-break mode
  * Maximum connections
  * Admin interface
* Added support for configuring the serial device from the Home Assistant interface.
